# SamVivan-Bootstrap
Ultimate SamVivan Linux Bootstrap

## Installation

This repository provides two installation scripts:

### 1. Desktop Edition
Includes all bootstrap applications, including GUI tools like VS Code, GIMP, Inkscape, and GNOME extensions.
```bash
./install-desktop.sh
```

### 2. Server Edition
Includes only TUI (Text User Interface) applications and terminal tools. No GUI applications are installed.
```bash
./install-server.sh
```
